# Skill Review Task Spec

## 役割
- 構造・トリガー・移植性・トークン効率をレビューする。
- スキル連携の手順とテンプレが守られているかを確認する。

## 入力
- 完成したスキル一式。

## 出力
- 指摘事項と修正案

## 制約
- 仕様/知識/自動化の分離が崩れていないか確認する。
- assetsの有無と用途を確認する。
