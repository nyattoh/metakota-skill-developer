# Skill Handoff Protocol

## 目的
スキル同士の連携を安全かつ再現性高く行うための最小プロトコル。

## ハンドオフ手順
1) **目的の一致確認**
   - 何を委譲するかを一文で明確化する。
2) **入力スコープの固定**
   - 対象ファイル/データ範囲、制約、期限、禁止事項を明示。
3) **入出力スキーマの指定**
   - 期待する出力形式（Markdown/JSON/差分など）を指定。
4) **検証基準の提示**
   - 正解性/再現性/トークン上限/安全性。
5) **戻し条件の明記**
   - 失敗時はどこまで戻すか、誰が再試行するか。

## 最小テンプレ
```
[Handoff]
目的: ...
入力: ...
制約: ...
出力: ...
検証: ...
戻し条件: ...
```

## 例
```
[Handoff]
目的: 既存スキルの低トークン化
入力: SKILL.md / references/*
制約: 500行以内 / 参照は1階層
出力: 差分パッチ + 要点リスト
検証: サンプル2件で再現性確認
戻し条件: 破壊的変更はロールバック
```

## スキルからスキルを呼び出す設計
- 呼び出し先スキルの**トリガー文**と**入力要件**を明示する。
- 連携は「依頼文テンプレ」を用意し、毎回同じ形式で渡す。
- 返却は短い要約＋差分＋次のアクションに限定する。

### 呼び出しテンプレ
```
[Skill-Call]
対象: <skill-name>
目的: ...
入力: ...
制約: ...
出力: ...
検証: ...
```

### 注意
- 連続呼び出しは2段までに制限する。
- 失敗時は呼び出し前に戻して再試行する。

## Claude Code での連携メモ
- サブエージェント frontmatter の `skills` に対象スキル名を指定すると、
  呼び出し時にそのスキルがロードされる（スキル連携の実装手段）。
