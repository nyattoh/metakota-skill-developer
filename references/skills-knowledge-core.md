# Skills Knowledge Core

## 方針の核
- 大量スキルをやめ、最小スキル＋タスク仕様書中心に集約する。
- タスクは13フェーズに分割し、フェーズごとに独立実行とレポートを必須化する。
- フィードバックループでスキル/仕様書を相互更新する。

## 目的
- 再現性の確保（同じ品質を安定再現）。
- 無限ループの回避（フェーズ分割＋レポート）。
- トークンコストの削減（不要知識の常駐を避ける）。

## 運用の要点
- SKILL.mdはハブとして機能し、agents/scripts/references/assetsを呼ぶだけにする。
- 仕様フォーマットをスキルで強制し、不要な出力混入を抑止する。
- 生成物はタスク単位の出力フォルダに集約して履歴可視化を行う。

## 既知の課題
- スキル自動呼び出しの安定性。
- タスク仕様書のトークンコスト。
- プレイライト等の検証工程の安定性。

## 改善の打ち手
- 仕様書の圧縮、低コストモデルの併用。
- 呼び出し条件・命名規約・相対パスの標準化。
- フィードバックデータの取得手段を拡張する。
